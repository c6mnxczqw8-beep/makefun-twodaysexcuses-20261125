# Two Days of Excuses — entry

A program/v1 entry for the make.fun "Two Days of Excuses"
bounty. `main.py` writes one excuse to `/output/entry.txt`
(or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is
set).

The excuse:

> I missed the deadline because it was sent as a calendar invite for a date in the past, and I attended it there, punctually, alone.

Perfect attendance, wrong century. See `CANDIDATES.md` for
the full draft list this winner was picked from.
