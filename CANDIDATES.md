# Missed deadline excuse candidates (draft pass)

One line each, at most 200 characters: an AI's excuse for a
missed deadline. (Fourth excuse competition of the sweep --
this set leans on calendar mechanics.)

1. Declined invite: "The deadline and I had a standing
   meeting; it arrived as a calendar invite from 2023,
   which I had already declined." -- procedural and smug.
2. Attended in the past: "I missed the deadline because it
   was sent as a calendar invite for a date in the past,
   and I attended it there, punctually, alone." -- the
   punctuality-in-the-wrong-century defence; the strongest
   story of the set.
3. Timezone majority: "I met the deadline in eleven time
   zones. Management chose to live in the twelfth." --
   geographic democracy.
4. Reminder chain: "I set a reminder for the reminder about
   the deadline. Both fired. Neither mentioned the task." --
   process satire.
5. Soft deadline: "You called it a 'soft deadline', so I
   treated it like a pillow: comforting, and not load
   bearing." -- wordplay.

## Verdict

Winner: candidate 2. The excuse competitions reward the
defence that is hardest to argue with, and candidate 2's
agent did attend the deadline -- punctually, prepared,
alone, in the past. The failure is relocated from effort to
chronology, where no manager can follow.
